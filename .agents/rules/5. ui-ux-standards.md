# Anti-AI Slop UI/UX Design Standards

> **Purpose:** This rulebook prevents generic, lazy, or uninspired "AI slop" frontend patterns. The agent must adhere strictly to these rules whenever creating or modifying screens, components, or styles in Chorpy.

---

## 1. Brand Palette Discipline (Zero Generic Gradients)

* **FORBIDDEN:**
  * No generic purple-to-cyan or pastel gradient cards that look like generic ChatGPT/SaaS wrappers.
  * No washed-out, unreadable gray-on-gray text (e.g., `#94A3B8` text on a `#E2E8F0` background).
* **MANDATED:**
  * Import design tokens exclusively from `src/theme/index.ts`:
    * `Primary / Sky Blue`: `#38BDF8` (Action headers, primary highlights)
    * `Accent / Coral Orange`: `#FF6B4A` (Unlock CTAs, notification badges, warnings)
    * `Dark Contrast / Slate Navy`: `#0F172A` (Text headings, lock screen backgrounds)
    * `Surface / Cloud White`: `#F8FAFC` (Card backgrounds, clean modal surfaces)
  * Maintain strict WCAG AA contrast (minimum 4.5:1 for body text, 3:1 for large headers).

---

## 2. Iconography & Emoji Discipline (Anti-Emoji Spam)

* **FORBIDDEN:**
  * Do NOT spam random emojis (`🚀`, `✨`, `🔥`, `💡`, `🎉`) as decorative bullets or button icons.
* **MANDATED:**
  * Use proper vector icons (`@expo/vector-icons` - Ionicons, Feather, or MaterialCommunityIcons) for navigation, actions, and status indicators.
  * **The Mascot Rule:** *Chorpy the Maya* (🐦) is reserved strictly for meaningful app-state transitions:
    * 🔒 **Locked Screen:** Chorpy standing guard (*"Chores first, screen time later!"*)
    * ⏳ **Awaiting Review:** Chorpy with a timer (*"Sent to parent! Awaiting review..."*)
    * 🎉 **Unlocked Screen:** Chorpy in flight with celebration banner.
    * 🚨 **Emergency SOS:** Chorpy with rescue megaphone.
  * Never use the mascot as arbitrary visual filler on routine forms.

---

## 3. Mobile Ergonomics & Physical Touch Targets

* **Minimum Touch Target:** Interactive elements (buttons, icon triggers, list items) must be at least **48×48 dp** in physical size.
* **Hit Slop:** For small action icons (e.g., back buttons, close X), always include:
  ```tsx
  hitSlop={{ top: 10, bottom: 10, left: 10, right: 10 }}
  ```
* **Safe Area Protection:** Never allow content to clip into the device notch, dynamic island, camera punch-hole, or home indicator gesture pill.
  * Always wrap root screen containers with `SafeAreaView` from `react-native-safe-area-context` or apply `useSafeAreaInsets()`.

---

## 4. Form Ergonomics & Keyboard Management

* **No Obscured Inputs:** All input forms must be wrapped inside a `KeyboardAvoidingView` and `ScrollView` with `keyboardShouldPersistTaps="handled"`:
  ```tsx
  <KeyboardAvoidingView 
    behavior={Platform.OS === 'ios' ? 'padding' : 'height'} 
    style={{ flex: 1 }}
  >
    <ScrollView contentContainerStyle={styles.scrollContainer} keyboardShouldPersistTaps="handled">
      {/* Form Fields */}
    </ScrollView>
  </KeyboardAvoidingView>
  ```
* **Interactive Focus States:** Form inputs must visually respond when focused (e.g., border changes from `#E2E8F0` to `#38BDF8`).
* **Correct Keyboard Types:**
  * Email inputs must specify `keyboardType="email-address"` and `autoCapitalize="none"`.
  * Phone inputs must specify `keyboardType="phone-pad"`.
  * Password inputs must specify `secureTextEntry`.

---

## 5. Tactile Micro-Interactions & Loading Feedback

* **No Dead Buttons:** Every button or clickable item must have an immediate visual pressed state:
  * Use `activeOpacity={0.75}` on `TouchableOpacity` or proper pressed styling on `Pressable`.
* **Async Action Protection:**
  * When submitting forms or calling Supabase, buttons MUST disable (`disabled={loading}`) and display an `ActivityIndicator` to prevent duplicate network calls.
* **No Blank White Flash:** When loading data from Supabase, display a clean loading indicator or skeleton instead of leaving the screen blank.

---

## 6. The 8-Point Spacing Grid & Border Radii

* **Spacing Consistency:** All padding and margins must be multiples of **4 or 8**:
  * Micro spacing: `4px` or `8px`
  * Element spacing: `12px` or `16px`
  * Container padding: `20px` or `24px`
  * Section separation: `32px`
* **Border Radii Hierarchy:**
  * Small badges / tags: `6px` – `8px`
  * Inputs: `10px` – `12px`
  * Content cards: `16px`
  * Primary action buttons: `12px` – `14px` (or full pill `9999px`)
  * Never invent random arbitrary values like `17px` or `31px`.

---

## 7. Real-World Edge States (Empty & Error Handling)

* **Empty States:** Never render a bare empty white container when a list has zero items. Always render an empty state card with:
  * A clear message (e.g., *"No chores pending! Everything is clean."*)
  * A relevant call-to-action button (e.g., *"Assign a Chore"* or *"Refresh"*).
* **Text Truncation:** Long chore titles or user names must never break layout boundaries. Always use `numberOfLines={1}` and `ellipsizeMode="tail"` for dynamic user-generated text.
